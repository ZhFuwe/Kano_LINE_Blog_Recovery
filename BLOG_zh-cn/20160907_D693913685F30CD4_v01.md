今日は鹿乃3rdシングルのリリース日だよ〜昨日のフラゲ報告、今日起きてからのゲット報告本当にありがとう。毎回、不安と緊張でガクブルしてるからみんなからの反応に救われてます( ･ᴗ･̥̥̥  )

今天是鹿乃第三张单曲的发售日哦〜感谢大家昨天提前买到手的报告，还有今天醒来后顺利入手的报告。每次我都因为不安和紧张而瑟瑟发抖，是大家的反应一次次拯救了我( ･ᴗ･̥̥̥  )

全員に反応は返せないですが、悲しみの取得漏れ以外は全員ありがたく読ませていただいています。もちろんブログコメントも！

虽然没法一一回复大家，但除了那些（遗憾地）漏掉没看到的以外，大家的每条反应我都心怀感激地读过了。当然，博客里的评论也是！

一人一人みんなからの反応があるから、みんなが歌を聴いてくれるからこうしてCDがまた出せたし、ライブもできたし、まだまだ心が折れずにこうして歌い続けることができています。感謝してもしきれないね。本当にありがとうっ

正因为有大家一个一个的回应、正因为大家在听我唱歌，我才能这样一次次发行CD、举办演唱会，也才能不气馁地继续唱下去。真是怎么感谢都不够呀。真的谢谢你们！

さてさて！昨日は都内のお店に挨拶まわりをさせていただいてきましたよ〜〜どこいっても今回のアーティストイラストかなり…その…ハレンt…目立ちますねって言われましたふふふ( ˊᵕˋ* )

那么那么！昨天我上东京市内的各家店去打招呼啦〜〜不管走到哪家店，大家都说这次的歌手插画相当……那个……破廉……挺显眼的，被这么说啦，嘿嘿嘿( ˊᵕˋ* )
